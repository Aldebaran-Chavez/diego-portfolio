SQLI #1 — Authentication Bypass Lab

Docker Lab #SQLI #Docker #Web

Lab Setup Instructions

Create a directory on your system and place the following 4 files inside. Then, launch the lab environment using Docker Compose.

docker-compose.yml 
version: '3.8'
services:
  db:
    image: mysql:5.7
    container_name: sqli_db
    environment:
      MYSQL_ROOT_PASSWORD: rootpassword
      MYSQL_DATABASE: lab_sql_injection
    ports:
      - "3306:3306"
    volumes:
      - ./init.sql:/docker-entrypoint-initdb.d/init.sql
    restart: always
  web:
    build: .
    container_name: sqli_web
    ports:
      - "8001:80"
    volumes:
      - .:/var/www/html
    depends_on:
      - db
    restart: always
Dockerfile 
FROM php:7.4-apache
RUN docker-php-ext-install mysqli pdo pdo_mysql
RUN a2enmod rewrite

Deployment Commands

Open your terminal in the directory where you saved the files and execute the following commands:

Build and start the laboratory containers:

Terminal 
sudo docker compose up -d --build

Access the application via web browser at:

http://localhost:8001

Stop and remove the laboratory containers when done:

Terminal 
sudo docker compose down -v
