We note that output .txt files inside /scripts are owned by root, indicating periodic automated execution.

To confirm periodic task execution, we create a process monitoring script inside /tmp:

#!/bin/bash

old_process="$(ps -eo user,command)"

while true; do
	new_process="$(ps -eo user,command)"
	diff <(echo "$old_process") <(echo "$new_process") | grep "[\>\>]" | grep -v "kworker|procmon"
	old_process="$new_process"
done
